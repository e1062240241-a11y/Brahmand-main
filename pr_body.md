## 🔍 What
Removed unused imports from various backend routes. Specifically, removed `APIRouter` from multiple library routes (where it's dynamically generated by `_loader.build_router`), as well as unused types, helper functions, and dependencies in `home_routes.py`, `katha_routes.py`, `messaging_routes.py`, `nettyfish_auth_routes.py`, and `circle_routes.py`.

## 🎯 Why
These imports were identified as unused by `pyflakes`. Removing them cleans up the file headers and prevents confusion about what dependencies the route actually requires. Dead code in the form of unused imports clutters the codebase and provides zero value.

## ✅ Verification
1. Confirmed removals via `pyflakes backend/routes/`.
2. Verified that removed symbols are not used in the respective files.
3. Verified syntax correctness across modified files using `python -m py_compile`.

## 📊 Impact
- Cleaned up 13 route files.
- Removed around 20 lines of unused imports.
- No functionality changes; strict zero-risk scope maintained.
