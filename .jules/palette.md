## 2024-05-19 - Adding accessibility to dynamic modal states
**Learning:** In React Native, `ActivityIndicator` and dynamic modal state changes (like moving from a form to a loading state to a success state) are often entirely silent to screen readers by default.
**Action:** Always add an `accessibilityLabel` to `ActivityIndicator` components. For dynamically rendering success/error views within a modal, apply `accessibilityLiveRegion="polite"` and `accessibilityRole="alert"` to the parent container to force screen readers to announce the state change correctly.
## 2024-03-24 - [Add accessibility attributes to UploadProgressBanner]
**Learning:** React Native's `Animated.View` components that conditionally render loading states (like the upload progress banner) need `accessibilityLiveRegion="polite"` and `accessibilityRole="alert"` so screen readers dynamically announce the progress and status changes without requiring the user to manually focus them. Additionally, generic `ActivityIndicator` components inside such views need a descriptive `accessibilityLabel` (like "Compressing media") to be meaningful to screen readers.
**Action:** When creating animated or conditional loading banners/toasts in React Native, ensure the root container has `accessibilityLiveRegion="polite"` and `accessibilityRole="alert"`, and add `accessibilityLabel` to any nested loading indicators.
