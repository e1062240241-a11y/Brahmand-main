## 2024-07-23 - [Optimizing N+1 Database Queries in Python Loops]
**Learning:** Found multiple instances where a single `db.get_document` call inside a loop iterating over a list of document IDs (`user_community_ids`) creates an N+1 query bottleneck. While `db.get_documents_batch()` exists, using `asyncio.gather` dynamically provides cleaner, safer, and idiomatic Python scoping in conditional logic blocks (`if/else`) without relying on specific custom wrapper structures. Also learned that assigning conditional caches requires defensive programming (e.g., `comms_map = None` upfront) to satisfy strict linters and prevent `UnboundLocalError` in downstream logic branches.
**Action:** When fixing N+1 database queries inside loops in Python backends, declare the cache variable explicitly as `None` in the highest relevant scope to avoid unbound local errors. Then, use `asyncio.gather(*(db.get_document(collection, uid) for uid in uids))` to concurrently fetch and map the results, ensuring dictionary lookups like `.get()` handle missing keys safely.
